# 环境与依赖

维护者本地已验证：Python 3.10.12、PyTorch 2.5.1+cpu、torchvision 0.20.1+cpu、NumPy 1.26.4。requirements.txt 固定本次安装的完整依赖版本。发布仓库不包含虚拟环境，需要先安装依赖。

创建环境并完成依赖安装后：

```bash
source .venv/bin/activate
python -m unittest discover -s tests -v
```

在新机器上先建立 Python 3.10 虚拟环境，再运行 `python -m pip install -r requirements.txt`。本机缺少系统 ensurepip，本次采用隔离安装的 virtualenv 建立环境；必要时可在项目内使用：

```bash
python3 -m pip install --target .bootstrap virtualenv
PYTHONPATH=.bootstrap python3 -m virtualenv .venv
.venv/bin/python -m pip install -r requirements.txt
```

可运行路径不再依赖旧 Detectron2 的 CUDA 编译，图像编码器改用明确映射的 torchvision R101/FPN 适配器。CPU 路径已验；GPU、混合精度与原 CUDA 算子数值一致性未验。纯 PyTorch 参考算子较慢，不能据本次小样本测试判断全量评测速度。
