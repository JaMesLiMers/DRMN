# 数据下载与准备说明（本轮不下载）

此文档供之后使用仓库的人准备数据。本次没有下载、解压或运行真实数据集；当前发布范围允许不附 checkpoint。

## 1. 官方下载入口

| 资产 | 下载入口 | 需要的内容 |
|---|---|---|
| COCO 2017 图片 | [COCO 官方下载页](https://cocodataset.org/#download) | train2017、val2017 图片；只评测时至少准备 val2017 |
| COCO panoptic 标注 | [COCO 官方下载页](https://cocodataset.org/#download) | 2017 panoptic annotations，包含 panoptic_train2017.json / panoptic_val2017.json 和 RGB 分割 PNG |
| PNG 叙述标注 | [PNG 官方项目页](https://bcv-uniandes.github.io/panoptic-narrative-grounding/) | png_coco_train2017.json、png_coco_val2017.json |
| 目录与原始说明 | [PNG 官方仓库](https://github.com/BCV-Uniandes/PNG#dataset-preparation) | 数据资产与 split 定义 |
| 一阶段预处理参考 | [PPMN 官方仓库](https://github.com/dzh19990407/PPMN) | dataloader JSON 生成流程 |

链接核对日期：2026-09-19。项目页依赖 JavaScript；若当前下载按钮或存储服务不可用，应以官方仓库/项目维护者给出的最新地址为准，不使用来历不明的替代标注。

PNG 原基线提供的 mask/semantic 等预计算特征不是本仓库所需的四层 FPN + BERT NPZ，不能直接互换。本仓库使用数据原始图片、panoptic 标注和 PNG 叙述。无需为了本仓库下载原基线的 proposal 特征。

## 2. 手工解压后的目录

```text
/path/to/png/
├── images/
│   ├── train2017/                # COCO JPG
│   └── val2017/
└── annotations/
    ├── png_coco_train2017.json
    ├── png_coco_val2017.json
    ├── panoptic_train2017.json
    ├── panoptic_val2017.json
    └── panoptic_segmentation/
        ├── train2017/            # 对应 split 的 RGB 分割 PNG
        └── val2017/
```

不同压缩包可能带有额外一层目录，应按真实解压结果移动/指定路径。文件名与 COCO image_id、JSON 的 file_name 必须一致。不要把 instance/stuff 标注替代 panoptic 标注，也不要把 COCO2014 直接当作 COCO2017。

## 3. 生成本仓库需要的 dataloader JSON

在仓库根目录、已安装 requirements 的环境中运行：

```bash
python tools/preprocess_annotations.py --data_dir /path/to/png --splits val2017
# 需要训练划分时：
python tools/preprocess_annotations.py --data_dir /path/to/png --splits train2017
```

脚本使用仓库内的 BERT 词表，不自动下载模型；只读已有标注并生成同目录的 png_coco_*_dataloader.json，不需要 DRMN checkpoint。它移植保存的 WordPiece/boxes/noun_vector/labels 算法，修复了旧代码写死的服务器输出路径。已有输出文件时拒绝覆盖。分词不对齐的记录按原算法排除，并在终端报告数量；使用者应保存该记录。

## 4. 编码特征与评测（需要之后提供的完好权重）

当前不发布 DRMN checkpoint，以下命令是资产齐备后的使用方式，不表示本轮已执行或可在没有权重时完成：

```bash
python tools/encode_data.py --config configs/drmn.yaml \
  --checkpoint /path/to/valid_drmn.pth \
  --png-json /path/to/png/annotations/png_coco_val2017_dataloader.json \
  --panoptic-json /path/to/png/annotations/panoptic_val2017.json \
  --panoptic-masks /path/to/png/annotations/panoptic_segmentation/val2017 \
  --images /path/to/png/images/val2017 --output /path/to/prepared_val
python tools/evaluate.py --config configs/drmn.yaml \
  --checkpoint /path/to/valid_drmn.pth --data /path/to/prepared_val
```

PNG/PPMN 的公开模型不能直接作为 DRMN 的完整权重加载。官方预训练 FPN/BERT 也只覆盖冻结编码器，不能替代 DRMN 已训练头部。新增 encode_data.py 的 --fpn-weights / --bert-weights 可独立加载冻结编码器，不需要预先有 DRMN 头部权重；训练入口 train_epochs.py 消费这些特征。获取权重及按 epoch 训练、恢复的命令见 [英文流程说明](workflows.md)。本轮没有下载权重或真实数据，也没有执行模型训练。

## 5. 数据和权重的发布约定

数据集从各自官方渠道获取，仓库仅附说明，不重新打包数据。当前不附可用 checkpoint、不提供虚构的权重下载链接；本地损坏备份只保留为恢复证据，不上传为模型发布物。
