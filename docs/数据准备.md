# 数据准备与格式

## 原始数据路径

需要：COCO2017 图片目录、panoptic JSON、RGB 编码的 panoptic PNG 掩码，以及原 PNG 预处理文件 png_coco_*_dataloader.json（含 image_id、caption、noun_vector、labels、boxes）。当前备份不包含完整数据；不自动用第三篇 COCO 数据替换。

`tools/encode_data.py --help` 列出所有路径参数。该工具先严格加载原 checkpoint 的主模型、图像编码器和文本编码器，再导出缓存。它不接受随机权重冒充论文权重。noun_vector 必须对应原 BERT WordPiece；截断会丢失标注时直接报错。默认处理全部有效记录，没有旧可视化代码中的 7 个 batch 筛选；--limit 仅用于显式小样本检查。

原始 RGB 图转 BGR，按 shortest edge/max size 缩放后归一化、补齐 32 倍数。掩码按原有顺序做双线性缩放、补齐、缩为 1/4、阈值 >0。评测在该几何尺度进行，原代码统一补零到 400×400 不改变非空掩码 IoU。

## 冻结特征 NPZ

一个文件对应一幅图及一条叙述，全部通过 allow_pickle=False 读取：

- fpn_p2/p3/p4/p5：[256,H,W]，相邻尺度减半，p2 高宽为 8 的倍数。
- language：[max_sequence_length,768]。
- noun_ids：[max_sequence_length]，0 为非名词或 padding，正整数为短语编号，包括 CLS/SEP 的零占位。
- targets_token：[有效名词 token 数,Hout,Wout]，训练验证用。
- phrase_intervals：[短语数+1]，对选中的 noun token 分段，首项 0。
- targets_phrase：[短语数,Hout,Wout]，评测用。
- ann_types：[短语数]，1 单数、2 复数。
- ann_categories：[短语数]，1 thing、2 stuff。

输出 SOURCE.json 保存数据来源及是否为合成数据。缓存能够复用冻结编码器输出，仍需保证生成时的权重、划分和预处理一致。

原包 test_features_compress.hdf5 的对象遍历报 wrong B-tree signature，不能直接作为完整可用数据缓存。小样本验证用显式生成的合成数据，不能报告为论文评测。
