# Deformable attention 算子恢复

原 models/toy_model 算子目录缺失。本轮采用 Deformable-DETR 官方模块与纯 PyTorch 参考核，保留参数名、初始化和采样计算，增加原调用需要的 debug 返回接口。源码来源：

- https://github.com/fundamentalvision/Deformable-DETR/blob/main/models/ops/modules/ms_deform_attn.py
- https://github.com/fundamentalvision/Deformable-DETR/blob/main/models/ops/functions/ms_deform_attn_func.py

上游来源见上述链接；本地恢复备份不随仓库发布。第三方 Apache 2.0 许可见 LICENSE-Deformable-DETR。仓库保留已有 MIT LICENSE，第三方代码适用其原许可。

这是有来源的重建依赖，不是找回的原自定义算子。纯 PyTorch 核支持自动求导和 CPU，适合验证但速度不等同原 CUDA 扩展。与原论文缺失算子的数值等价尚不能直接证明，需用完整权重和数据验证。位置编码改为跟随输入设备，计算公式不变。
