# 论文方法与当前代码

| 环节 | 当前实现 | 来源与验证 |
|---|---|---|
| 冻结 ResNet101 + FPN | drmn/models/frozen_encoders.py | 重建适配器；stride 放在 1×1、FrozenBN、BGR 归一化、sum FPN；538 项参数/缓冲区与原权重对应 |
| 冻结 BERT | models/encoder_bert.py、modeling.py、FrozenTextEncoder | 保留原模型；465 项状态名称和形状一致 |
| 多尺度 deformable 编码 | models/head_model/deform_encoder_head.py、deform_img_encoder.py | 编码器从缓存恢复；算子采用有来源的 PyTorch 参考核 |
| 初始匹配 | models/head_model/kernel_head_new.py | 保留原计算 |
| top-k 与迭代细化 | kernel_update_head.py、deform_iter_head.py、deform_txt_decoder.py | 原实现 + 缓存恢复 decoder；3 轮结构与 checkpoint 对应 |
| 中间监督 | runtime.stage_loss、losses/ | 累加每阶段 BCE + Dice；依据旧训练代码重建入口 |
| 短语聚合与评测 | evaluation/metrics.py | 先平均 token 概率再阈值；离散 Average Recall 与原 meters 数值对照通过 |
| PNG 预处理 | datasets/png.py、tools/encode_data.py | 根据原 loader 重建；已做合成标注检查，完整真实集未验 |

主模型 281 项状态全部与原 checkpoint 同名同形状。整理前后主模型在相同随机参数、相同合成输入、相同重建算子下四阶段输出差异均为 0。此验证不包含已丢失的原 CUDA 算子，也不证明原论文指标已复现。

原缓存 decoder 的调试输出有字典/列表两个版本，采用与保存的 kernel_update_head 调用一致的字典版。原编码器声明但未调用的文本分支保持不变，未擅自改算法。

configs/drmn.yaml 的采样点数 100 来自源代码默认值，最终实验的该参数尚未锁定；参数名/形状无法证明采样点数相同。消融配置不虚构。

本轮补充：图像编码器已与归档 Detectron2 在同参数、两种合成尺寸及非默认 BN 统计量下逐层数值对照，四层差异均为 0。论文 Dice 分母与原实现不同，详见 最终一致性核对.md；不能把方法概括对应当成每个公式完全相同。
