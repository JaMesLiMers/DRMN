# DRMN 最终代码一致性核对

核对日期：2026-09-19。范围按用户最新要求：不下载/准备真实数据，不做完整训练，允许不提供 checkpoint；进行论文、保存源码、缓存恢复实现与整理版的代码及合成测试核对。

**结论：主要方法和已测试计算链与保存实现相符，可整理为不附权重的研究代码版本；不能签署“论文公式、最终实验配置和效果全部无差异”的结论。发现的差异与证据限制如下。**

## 本轮修复

1. 图像编码器 FrozenBN 在非默认统计量下原先有约 10^-6 的相对浮点差异。改为原 Detectron2 的归一化计算路径后，两种输入尺寸、非默认统计量下四层特征对照均为零差异。该证据来自合成输入与共同参数，不是对原训练权重的评测。
2. 补充 tools/preprocess_annotations.py，从官方 PNG 原始 JSON 生成 dataloader JSON；保留原标签算法，改用本地词表，修复硬编码输出路径，防止覆盖已有文件。无需真实数据即可用小型构造标注验证。

## 不能抹平的论文/原代码差异

### Dice 公式

本地论文 camera-ready.tex 的 Dice 分母是 Σp + Σy。保存的 dice_loss.py 使用 Σp² + Σy² + 2ε，ε=0.001。整理版保留原代码；测试明确验证了这个差异，不把两种公式称为等价。

这影响训练目标的表述；加载同一权重做推理时不计算 Dice，因此此差异本身不改变推理输出。本轮不重训，也不把损失偷偷改成论文公式。

### 最佳实验的非参数配置

num_points=100 有源码默认值和两个完整消融日志支持；最佳实验日志开头损坏，不能证明其配置必然相同。两个消融日志记录 seed=3407、num_stages=1，但目录名称写 3 decoder layers；说明命令行值与实际构造可能不一致，不能照搬它们覆盖主模型。

主模型 3 轮依据 checkpoint 参数而非目录名确认。当前 seed=0 只用于确定性工程验证，不声明为原最佳实验随机种子。主配置中这些证据等级已标注。

### Deformable 算子

原自定义算子文件缺失；当前使用 Deformable-DETR 官方纯 PyTorch 参考核，已做采样已知值及梯度检查。论文的双线性采样、多尺度偏移和注意力模式有实现对应，但不能凭这些检查证明丢失的原 CUDA 算子没有额外修改。

### 训练入口与真实评测

head_example.py 的完整源码没有恢复。2026-09-20 补充重建 train_epochs.py：按 epoch 训练、梯度累积、验证、last/best 保存、epoch 边界恢复和 torchrun 入口。单进程及双进程 CPU 前向/反向通过，未做完整训练或 GPU 验证。批次及恢复规则是明确记录的新工程协议，不能称为恢复了历史训练轨迹。旧 train.py 保留有限步诊断功能。

本轮按要求不运行真实数据。没有可用原 checkpoint，故不确认 62.9% 或任何真实分割质量；历史 62.942% 日志仅作为原实验记录。
